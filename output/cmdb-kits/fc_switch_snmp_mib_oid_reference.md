# 光纤交换机 SNMP CMDB 与监控采集参考

本文档面向基于 SNMP 的光纤交换机配置采集和监控采集脚本开发。品牌覆盖通用标准 MIB、Brocade/博科、Huawei/华为。

说明：

- 表格中的表类 OID 需要 `snmpwalk`，最终实例 OID 为 `表列 OID + 索引`。
- 不同型号、固件版本、OEM 关系会影响私有 MIB 支持情况。华为 SNS 系列中部分型号是 Brocade OEM，常见会暴露 Brocade `1.3.6.1.4.1.1588` 私有树。
- 开发时建议同时保存 `raw_oid`、`raw_value`、`decoded_value`，避免 MIB 枚举解析差异导致数据丢失。
- Zone 完整配置、当前激活 ZoneSet、端口连接的远端设备 WWN 在部分设备上 SNMP 只暴露摘要或邻接信息，完整配置通常还需要 CLI、REST API 或厂商 SDK 补充。

### 4.4 Zone 相关表

这里的 `FCMGMT-MIB` 指常见于 Brocade/FC 交换机的 Fibre Alliance 管理树 `1.3.6.1.3.94`。标准 Zone 对象主要是 `connUnitZoneTable` 和 `connUnitZoningAliasTable`，它们能提供 ZoneSet/Cfg 名称、Zone 名称、Zone 成员 ID、Alias 名称等信息，但并不是所有厂商都会完整实现，也不一定能表达完整的 zoning 数据库、defined/effective config 差异、cfg 组成关系和所有成员类型。

#### 4.4.1 connUnitZoneTable

根 OID：`1.3.6.1.3.94.1.13.1`

表索引通常由 `connUnitId`、`connUnitZoneIndex` 等复合索引组成。开发时不要假设索引是简单整数，建议直接按列 OID 后缀分组。

| 采集字段 | OID | 说明 |
|---|---|---|
| Zone 索引 | `1.3.6.1.3.94.1.13.1.1` | `connUnitZoneIndex`，Zone 表内部索引 |

#### 4.4.3 标准 SNMP Zone 采集边界

| 需求 | FCMGMT-MIB 支持情况 | 建议 |
|---|---|---|
| Zone 名称 | 通常可通过 `connUnitZoneName` 获取 | 可采 |
| ZoneSet/Cfg 名称 | 通常可通过 `connUnitZoneSetName` 获取 | 可采 |
| Zone 成员 WWN | 部分设备通过 `connUnitZoneMemberId` 获取 | 可采但需实机验证 |
| Alias 名称与成员 | 部分设备通过 `connUnitZoningAliasTable` 获取 | 可采但需实机验证 |
| 登录到 Fabric 的设备 WWN | 不属于 Zone 表，可通过 SNS/Name Server 或端口邻接表补充 | 结合 `connUnitSnsTable`、链路表、CLI |
| Active ZoneSet | 标准表未必明确标记 active/effective | 建议 CLI/API 补充 |
| Defined Config vs Effective Config | 标准表通常无法可靠区分 | 建议 CLI/API 补充 |
| ZoneSet 包含哪些 Zone | 可通过 `zone_set_name + zone_name` 聚合推导，但不一定完整 | SNMP 可做摘要，配置一致性需 CLI/API |
| Zone 成员类型精确枚举 | 厂商实现差异较大 | 保留原始数字值和解析值 |
| Zone 成员顺序、注释、完整语法 | 通常不支持 | CLI/API |
| LSAN、Peer Zone、Traffic Isolation、Admin Domain 等高级 zoning | 标准表通常不完整 | 厂商接口 |

#### 4.4.4 相关但不是 Zone 的 connUnitSnsTable

`1.3.6.1.3.94.1.15` 在常见 Fibre Alliance 管理树中是 Name Server/SNS 相关表，不应作为通用 Zone Member 表。它适合用于补充“当前登录到 Fabric 的设备/端口 WWN、FCID、设备类型”等运行态信息，再与 Zone 成员做交叉校验。

| 信息 | OID 根 | 说明 |
|---|---|---|
| Name Server/SNS 表 | `1.3.6.1.3.94.1.15` | 登录设备、端口 WWN、Node WWN、FCID、设备类型等，列定义按具体 MIB/设备 walk 结果解析 |

建议用途：

- 判断 Zone 成员 WWN 当前是否在线。
- 根据远端 Port WWN/Node WWN 反查连接设备。
- 与 `connUnitLinkTable`、`connUnitPortTable`、Brocade `nsshow/nsallshow` 做数据互补。

建议脚本处理：

- 优先 walk `1.3.6.1.3.94.1.13.1` 和 `1.3.6.1.3.94.1.14.1`，不要使用不存在或未标准化的 `1.3.6.1.3.94.1.15` 作为通用 Zone Member 表。

## 7. 开发注意事项

- OID 返回值里的 WWN 可能是 OCTET STRING，也可能是冒号分隔字符串。统一标准化为小写冒号格式。
- 速率可能返回 Gbps 枚举、Mbps、bps 或厂商枚举。采集层建议统一输出 `speed_bps`，保留 `raw_speed`。
- 状态枚举不要只保存中文/英文描述，必须保存数字值和解析值。
- 计数器使用 `Counter64` 优先，`Counter32` 只作为兼容。
- SNMP walk 大表时设置超时、重试、最大 OID 数，避免单台异常设备拖垮采集批次。
- 对私有 MIB 列表做能力探测，不要假设同品牌所有型号都支持同一批 OID。
- CMDB 采集和监控采集建议分离频率。配置类低频，状态/指标类高频。
