# guide.md 输出模板（逐字使用，只替换 «占位符»）

> 本文件是 guide.md 的**唯一排版真源**。生成时：按顺序填 «...» 占位符、按需复制「步骤小节」「阶段章」模板块，**不增删不改其他任何字面结构**（标题层级/引导语/分隔线/附录表头）。这保证任意两次输出、任意 LLM 执行，格式逐字节一致。

## 文档级模板

```markdown
# «主题名» · 图文操作指引

> 由 browser-recorder session `«session目录名»` 生成（«N» 动作 / «M» 选用截图 / «K» 事件）。
> 红框=操作位置；«tab 说明：单 tab 写 t0=主标签页；多 tab 列 t0=主标签页，t1=第«n»步弹出的新标签页»。

---

«阶段章 × N（见下节模板块）»

---

# 附录：本录制涉及页面与接口概览

| 步骤 | 接口 | 说明 |
|---|---|---|
| «步骤编号» | `«接口路径»` | «一句话» |
| ... | ... | ... |

> 接口详细分析见 `api-report.md`（同目录）。
```

## 阶段章模板块（按 nav 大节点切分，复制 N 份）

```markdown
## «中文序号»、«阶段名（名词短语：登录 / 打开XX应用 / 填写XX信息…）»

### «阶段号».1 «动词短语步骤名»
«一句话操作说明：在哪点什么 / 输什么（输入值来自 action.value，password 写 ***）»
![«与标题相同的动词短语»](screenshots/«seq»-«phase».png)
```

**小节变体（只此三种，不得自创）**：

1. **标准小节**（上块原样）——单图步骤
2. **连排双图小节**（仅局部刷新类动作）：

```markdown
### «阶段号».«n» «动词短语»
«一句话说明»
![«短语»-点击处](screenshots/«seq»-before.png)
![«短语»-效果](screenshots/«seq»-after.png)
```

3. **无图小节**（图缺失/raced/failed）：

```markdown
### «阶段号».«n» «动词短语»
«一句话说明（含元素描述：元素 <tag>#<id> <text>，位于«上一可见元素的方位»）»
（本步无截图）
```

## 硬规则（生成时逐条自查）

1. 每小节**三要素顺序固定**：`### 标题` → 一句话说明 → 图（或"（本步无截图）"）——无第四要素
2. 图注 alt 文本 = 小节标题的动词短语，逐字一致（连排图加 `-点击处`/`-效果` 后缀）
3. 阶段章编号：`## 一、` `## 二、`…中文序号；小节 `### 1.1` `### 1.2`…阶段号.序号
4. 连续 input 到同一表单 → 合并一小节，每字段一行说明，只配一张图（最后字段的 after）
5. password 恒 `***`；URL/值原样不截断
6. 附录表只列业务接口（噪声折叠），行序=首次出现序
7. 文档头三行元信息（session 名/统计/红框说明）逐字模板，只替换占位内容
