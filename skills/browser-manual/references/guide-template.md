# guide.md 输出模板（逐字使用，只替换 «占位符»）

> 图片引用一律为压缩后的 `screenshots/«名».webp`（宽 1280 / q80，见 `scripts/prepare_guide_images.py`）。
> 本文件是 guide.md 的**唯一排版真源**。生成时：按顺序填 «...» 占位符、按需复制「步骤小节」「阶段章」模板块，**不增删不改其他任何字面结构**（标题层级/引导语/分隔线/附录表头）。这保证任意两次输出、任意 LLM 执行，格式逐字节一致。

## 文档级模板

```markdown
# «主题名» · 图文操作指引

> 由 browser-recorder session `«session目录名»` 生成（«N» 动作 / «M» 选用截图 / «K» 事件）。
> 红框=操作位置；«tab 说明：单 tab 写 t0=主标签页；多 tab 列 t0=主标签页，t1=第«n»步弹出的新标签页»。

---

«阶段章 × N（见下节模板块）»

---

# 附录：本录制涉及页面与接口概览

| 步骤 | 接口 | 说明 |
|---|---|---|
| «步骤编号» | `«接口路径»` | «一句话» |
| ... | ... | ... |

> 接口详细分析见 `api-report.md`（同目录）。
```

## 阶段章模板块（按 nav 大节点切分，复制 N 份）

```markdown
## «中文序号»、«阶段名（名词短语：登录 / 打开XX应用 / 填写XX信息…）»

### «阶段号».1 «动词短语步骤名»
«一句话操作说明：在哪点什么 / 输什么（输入值来自 action.value，password 写 ***）»
![«与标题相同的动词短语»](screenshots/«seq»-«phase».webp)

#### «阶段号».1.«m» «动词短语子步骤名（仅当一节内动作需要再分组时使用）»
«一句话操作说明»
![«与标题相同的动词短语»](screenshots/«seq»-«phase».webp)
```

**层级按内容需要伸缩（不强制用满）**：`##`（章）与 `###`（节）为基本层级；一节内动作多、需要再分组时用 `#### 1.1.1` 子节，必要时可再下探 `##### 1.1.1.1`。三要素与图片始终挂在**最细一级**标题下；下面三种小节变体同样适用于任意最细层级（变体示例中的 `### «阶段号».«n»` 即指最细一级标题，可为 `#### 1.1.1` 等）。

**小节变体（只此三种，不得自创）**：

1. **标准小节**（上块原样）——单图步骤
2. **连排双图小节**（仅局部刷新类动作）：

```markdown
### «阶段号».«n» «动词短语»
«一句话说明»
![«短语»-点击处](screenshots/«seq»-before.webp)
![«短语»-效果](screenshots/«seq»-after.webp)
```

3. **无图小节**（图缺失/raced/failed）：

```markdown
### «阶段号».«n» «动词短语»
«一句话说明（含元素描述：元素 <tag>#<id> <text>，位于«上一可见元素的方位»）»
（本步无截图）
```

## 硬规则（生成时逐条自查）

1. 每个**最细小节**三要素顺序固定：`«层级标题»`（动词短语）→ 一句话说明 → 图（或"（本步无截图）"）——无第四要素
2. 图注 alt 文本 = 小节标题的动词短语，逐字一致（连排图加 `-点击处`/`-效果` 后缀）
3. 标题层级与编号（按内容实际需要划分，不强制用满）：`#` 文档标题（不编号）；`## 一、`「二、」…章（中文序号）；`### 1.1` `1.2`…节（章号.序号）；`#### 1.1.1` `1.1.2`…子节（节号.序号，按需）；`##### 1.1.1.1`…更深子节（极少用）。三要素与图挂在**最细一级**标题下
4. 步骤粒度=逐点击：每个动作独立成一小节（表单字段逐个成节）；仅三类合并——同一控件的「点击+录入/勾选」（如输入框点击并输入、勾选框勾选）、「下拉展开+选项点选」、「无状态变化的冗余重复点击」（同一按钮连点、反复开合同一面板）
5. password 恒 `***`；URL/值原样不截断
6. 附录表只列业务接口（噪声折叠），行序=首次出现序
7. 文档头三行元信息（session 名/统计/红框说明）逐字模板，只替换占位内容
