# 存储设备 SNMP 品牌支持

| 品牌/平台 | 识别方式 | SNMP 覆盖 | 备注 |
|---|---|---|---|
| 通用阵列/NAS | 标准 MIB | HOST-RESOURCES-MIB 容量、已用量、使用率 | 设备需暴露 hrStorage 表 |
| Huawei OceanStor | 身份树 `2011.2.91` / `34774` 或描述 | 阵列/池容量和使用率、状态、版本、控制器CPU/内存、硬件健康、LUN发现 | 不同 OceanStor 版本私有表可能不同 |
| NetApp FAS/AFF | 企业树 `789` 或描述 | 版本、故障磁盘；标准表兜底 | AFF 深度性能优先使用 HTTP API |
| XSKY SDS | 企业树 `48871` 或描述 | 集群总容量、已用容量 | XMS 深度对象优先使用 HTTP API |
| EMC Data Domain DD2500 | 企业树 `19746` 或描述 | 标准表兜底、设备识别 | 私有磁盘/文件系统表依 SNMP View |
| Dell iDRAC | 企业树 `674.10892` 或描述 | 标准表兜底、设备识别 | RAID/物理盘建议关联物理服务器 SNMP 套件 |

未识别品牌统一归类为 `generic`，不会因为缺少私有 MIB 而阻断标准容量采集。模板源自 Zabbix 5.4 导出。华为已用用户提供的 2026-11-11 walk 样本离线回放，非本环境直连真机验证；其他品牌尚未按实机返回校准。发布前仍需验证目标 SNMP View、单位和索引。
