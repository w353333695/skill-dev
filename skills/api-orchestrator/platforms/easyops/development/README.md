# EasyOps 开发材料

Hub 只保存可导入或部署的成品包及可导入模板，索引见 `../hub/INDEX.yaml`。

- `scripts/`：维护用源码与配套依赖；不是 Hub 成品。
- `tests/`：采集套件、监控套件的离线回归。工具回归随源码位于 `scripts/tools/tests/`。
- `docs/`：使用说明维护稿、MIB 参考等资料；面向用户的说明也应随成品包交付。
- `INDEX.yaml`：原源码条目的开发索引，保留历史与说明；不参与成品查重。

更新时维护源码和测试，验证后只将最终成品包回流 Hub，更新成品索引。不要将测试或缓存复制回 Hub。
