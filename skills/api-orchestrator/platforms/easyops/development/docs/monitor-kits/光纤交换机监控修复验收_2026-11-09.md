## 修复内容

1. 地址保持`$.ip`；端口为空/null/None/undefined时默认161，保留自定义端口，非空非法值明确报错；缺IP或认证参数提前失败，不猜测团体名。
2. SNMPv1/v2c/v3严格校验，v3安全级别与`$.auth.contextName`上下文同时用于预检和正式采集；动态CMDB认证参数关闭错误的二次密钥解析。
3. 使用sysDescr进行一次认证预检（3秒、零重试）；正式单命令10秒、零重试，直接启动子进程并确保超时终止与回收，不依赖外部timeout命令。
4. 修复NA、空值、NaN/Inf到浮点或整数的转换异常；缺失项跳过，不补零、不伪造健康状态。六采集阶段独立隔离，保留已取得的数据，全空明确报错。
5. 默认ERROR、可选DEBUG；日志、异常及stdout凭证脱敏；兼容Unicode，stdout输出ASCII安全JSON，异常带脱敏traceback及COLLECT_ERROR前缀。
6. 保留Brocade、Cisco、华为和通用分支及既有OID；修复FOS跨设备字典污染和厂商enterprise边界匹配，不新增未经验证OID。
