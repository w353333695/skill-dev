```json
  "samplerJobConfig": {"configId": "65ff7990d5665"},
  "uuid": "f907bc31-c391-4518-be14-fe50d827bfd8",

```

UUID取自该任务实例`executionHosts.uuid`，本例执行主机恰好也是目标，不能推广为总用目标UUID。`reportMetric=true`会触发指标上报。Cookie、追踪头和浏览器头不录入示例。

启用请求包括套件`instanceId`、真实`relateObjectId`、`notRequireJob=true`和`needUpdateJob`。`needUpdateJob=false`适用于指标、维度或指标集定义刷新，不更新已有任务；`true`会更新任务，必须先确认影响。不要把其他存储套件的`STORAGE@ONEMODEL`复制到Ping套件；关联模型须回读确认。资源响应中`collectorJob count=1`不证明运行任务存在，须查v2任务；不存在才创建，避免重复。激活刷新后回读别名指标维度、`relateMetricSets`和指标集映射。

动态IP仍使用`$.ip`，参数类型`cmdb`，`isFromSecret/isEncrypt`均false。前端入口需在当前进程明确为HTTPS；本轮不改部署环境变量。自签证书跳过校验仅限已确认入口，不是默认安全设置。
