# EasyOps 公共开发知识

本目录存放多个能力域、多个套件类型都适用的开发与交付知识。

## 归档范围

- 采集套件、监控套件、检查套件共用的包结构、ZIP 权限、导入失败、版本升级、文件保留规则。
- EasyOps 插件开发中跨类型复用的调试、验证和发布约定。
- 不依赖某个 CMDB 模型、监控指标集或单一套件实现的经验。

## 不应放入这里

- 仅 CMDB 采集任务、`resource_discovery_define.json`、采集参数映射：放 `../cmdb-kits/`。
- 仅监控指标、指标集、监控任务或监控结果：放 `../monitor-kits/`。
- 稳定的包格式和字段 schema：放 `../../formats/collector-kit/`。
- 可导入成品和已验证脚本源码/脚本成品包：放 `../../hub/`；Hub 不放半成品、测试、缓存或临时文件。仍在迭代的源码留在 `development/`，验收完成后归档到 `hub/scripts/`。

## 维护规则

1. 新增知识前先判断是否已有公共文档，优先更新已有文档，避免同一经验分散在 CMDB 和监控目录。
2. 发现某条知识被两个以上套件类型引用时，应从类型目录提升到本目录，并在原目录保留索引或迁移说明。
3. 事实必须注明验证环境、日期和适用范围；未实测内容标记为推断或待验证。
4. 交付后更新本目录、平台 README 和 Hub `INDEX.yaml` 的索引；已验证成品进入 Hub，临时验证文件进入 `tmp/`，未完成代码留在 `development/`。
5. 修改公共规则时同步检查 `skills/api-orchestrator/SKILL.md` 的读取和维护要求。
