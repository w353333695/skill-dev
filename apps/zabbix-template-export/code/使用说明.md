# Zabbix 5.4.5 全量模板导出

## 导出目标

脚本版本 1.1.0，Python 3.9+，纯标准库，不需要安装依赖。

**默认导出当前账号可见的全部模板**，不按品牌、设备类型或采集协议筛选。服务器、存储、交换机、路由器、防火墙等模板及自定义模板均纳入，非 SNMP 模板也保留，便于未来复用。按名称或 ID 指定范围时，会递归补齐可见父模板。

通过 `configuration.export` 保留服务端提供的原生模板结构，不自行裁剪监控项、OID、预处理、值映射、LLD 及原型、触发器、图形、模板宏和模板链接等配置。不同模板实际包含哪些内容，以服务端导出为准。

## 推荐执行方式：全量导出

在脚本所在目录执行，替换地址和用户名：

```sh
export ZABBIX_URL='https://你的Zabbix地址/zabbix'
export ZABBIX_USER='你的用户名'
python3 export_zabbix54_templates.py --all --timeout 300
```

程序隐藏输入密码。支持 `ZABBIX_PASSWORD` 环境变量，但不要把密码写入命令行或提交到仓库。
也支持 `ZABBIX_TOKEN`，设置后优先使用 Token，不再要求账号密码。

若从工作空间根目录运行，脚本路径为：

```sh
python3 tmp/zabbix-template-export/export_zabbix54_templates.py \
  --all --timeout 300 \
  --output-dir ./tmp/zabbix-template-export/exports
```

- 账号/Token 应具备所有目标模板的读取权限，角色应允许 `template.get` 和 `configuration.export`。无权限模板无法由脚本自动识别或导出；建议使用有全量模板可见性的专用只读账号，并核对模板数量。
- URL 可填站点地址或完整 `api_jsonrpc.php` 地址；子路径部署必须保留站点路径。
- 默认验证 HTTPS 证书。可信自签环境可显式追加 `--insecure`。
- 不写 `--all`、且不指定 `--name/--template-id` 时，同样默认全量导出。

## 输出与回传

每次在输出根目录创建唯一时间戳子目录，最后打印该目录的绝对路径：

- `templates.json`：原生模板导出结构，默认脱敏。
- `alert-rules.json`：告警触发器、触发器原型、关联监控项、函数、依赖、标签、预处理和值映射；其中 expression 与 recovery_expression 可用于整理 EasyOps 告警模板和阈值。
- `template-index.json`：API 和脚本版本、模板 ID/名称、父模板关系、告警数量和脱敏标记。

**两个文件一起回传**即可用于后续服务器、存储和网络设备监控适配分析。
默认脱敏社区名、密码、密钥及敏感宏值，保留普通宏值以便解释阈值和过滤规则。无法保证识别脚本正文中硬编码的秘密，分享前仍需人工审查。
`--include-sensitive` 会保留 API 实际返回的敏感值，本次不建议开启，也无法恢复 API 自身隐藏的值。
文件按 0600、运行子目录按 0700 创建（POSIX），不覆盖旧文件。

## 完整性边界

- 全量指**全部可见模板的配置**，不是整个 Zabbix 数据库备份。
- 不导出用户、接口密码、主机清单、主机级宏覆盖、全局宏值、实时值、历史值或运行错误。
- 只在主机上创建、没有写入模板的监控项不在本次导出范围内。
- 模板引用主机/全局宏时，实际运行时覆盖值不会自动补齐；秘密值也不应为调研目的回传。
- 父模板不可见、指定模板不存在、导出模板集合不匹配时直接报错，不当作完整导出。
- 全量导出通常比筛选导出更大；可调高 `--timeout`。极大环境若触及服务端限制，可按模板 ID 分批运行，每批均递归补父模板。

## 其他用法

```sh
# 查看全部可见模板ID、技术名、显示名
python3 export_zabbix54_templates.py --list

# 仅需要排错或分批时再缩小范围；选择器可重复
python3 export_zabbix54_templates.py --template-id 10929 --template-id 10402
python3 export_zabbix54_templates.py --name 'TEMP_PBC_PHY_DELL_IDRAC_SNMP'

python3 export_zabbix54_templates.py -h
python3 export_zabbix54_templates.py --version
```

## 验证与排错

仅接受 API 5.4.x。日志记录 API 方法和请求编号；错误含函数标记与 traceback，不主动打印请求体、原始响应或凭证。不自动重试登录，避免失败重试触发账号锁定。
退出码：0 成功、1 配置/API/导出失败、130 用户中止。

已通过 10 项离线测试，涵盖默认全量、存储/网络/非 SNMP 模板保留、显式筛选、父模板递归、脱敏、JSON-RPC 请求和文件权限；未连接你的实际 Zabbix 5.4.5 环境验证。

## Python 2 独立版本

另提供 `export_zabbix54_templates_py2.py`（版本 `1.0.2-py2`），Python **2.7.9+**，无第三方依赖，可单独复制运行，不依赖 Python 3 脚本。原 Python 3 版本不变。

```sh
export ZABBIX_URL='https://你的Zabbix地址/zabbix'
export ZABBIX_USER='你的用户名'
python2 export_zabbix54_templates_py2.py --all --timeout 300
```

同样隐藏输入密码；默认全量、递归父模板、默认脱敏、参数和输出文件与 Python 3 版一致。

```sh
python2 export_zabbix54_templates_py2.py --list
python2 export_zabbix54_templates_py2.py -h
python2 export_zabbix54_templates_py2.py --version
```

要求 2.7.9+ 是为了使用标准库证书校验上下文；缺少此能力时直接报错，不静默关闭验证。即使使用 `--insecure`，也不支持更早的 Python 2。

当前环境没有 Python 2 解释器：已通过 Python 2 语法解析检查，以及 Python 3 下的 8 项兼容分支/模拟 API 测试（中文、脱敏、默认全量、父模板、登录/登出、响应关闭及文件权限）；**尚未完成 Python 2 实机或真实 Zabbix 联调**。目标机器可执行 `python2 test_export_py2.py` 进行离线回归（测试文件需与脚本在同一可写目录）。


### Windows 报错修复（1.0.2-py2）

- 原先强制把 UTF-8 字节写入 Windows 控制台，会产生乱码，部分 Python 2 控制台还会报 `IOError: [Errno 0] Error`。新版对原生 Windows 控制台使用 Unicode 写入，其他输出按流编码处理。
- 缺参数时，原先 traceback 字节串参与 Unicode 日志格式化，会再次触发 `UnicodeDecodeError`、掩盖真正错误；新版先转换文本再记录。
- 原先先调用 `apiinfo.version`、再询问密码，API 地址返回 404 时不会出现密码提示。新版有效配置下先读取或询问密码，再联网；仍会先验证服务端版本，验证通过后才发送登录请求。
- `--all` 不替代 URL 和用户名；`-h` 仅显示帮助，不会要求密码。
- 已设置 `ZABBIX_TOKEN` 或 `ZABBIX_PASSWORD` 时不再询问密码，并打印认证来源（不打印凭证值）。

日志中的 `http://11.66.25.52/zabbix/api_jsonrpc.php` 返回了 404。请核对浏览器实际站点路径，不要盲目增加 `/zabbix`。如果 Zabbix 确实部署在根目录，PowerShell 可执行：

```powershell
python .\export_zabbix54_templates_py2.py --url http://11.66.25.52/api_jsonrpc.php --user easyops --all --timeout 300
```

如果实际是其他路径，应改为该站点路径下的 `api_jsonrpc.php`；密码提示出现不代表 API 路径已验证成功。HTTP 会明文传输凭证，正式使用优先使用站点提供的 HTTPS 地址。

当前没有 Windows/Python 2 实机环境，Unicode 控制台修复仍需目标机器验证。

### Python 2 Windows `LoadLibrary` 报错

如果看到 `LoadLibrary() argument 1 must be string, not unicode`，这是 Python 2 的 `ctypes` 在加载 Windows DLL 时不接受 Unicode 库名导致的。`export_zabbix54_templates_py2.py` 已更新到 `1.0.3-py2`，使用字节串 `kernel32.dll` 加载库，并将该异常作为控制台降级处理，不再阻塞密码输入或 API 导出。

## 变量配置运行

新版脚本不再从命令行接收 URL、用户名、密码、输出路径或筛选参数。请直接编辑 `export_zabbix54_templates.py` 顶部的 `ZABBIX_URL`、`ZABBIX_USER`、`ZABBIX_PASSWORD`、`OUTPUT_DIR`、`TEMPLATE_IDS`、`TEMPLATE_NAMES` 和 `EXPORT_ALL`，然后运行：

```sh
python3 export_zabbix54_templates.py
```

脚本会额外调用 `trigger.get`、`triggerprototype.get` 和 `item.get`，将告警规则、触发器表达式、恢复表达式、监控项预处理和值映射写入 `alert-rules.json`，用于开发 EasyOps 告警模板和阈值。
