# Zabbix 5.4 模板、告警规则与阈值导出

`export_zabbix54_templates.py` 使用 Python 3.9+ 标准库，只读调用 Zabbix API，导出模板原始结构以及开发 EasyOps 告警模板所需的触发器、触发器原型、监控项和阈值信息。

## 配置与运行

直接编辑脚本顶部变量，不使用 URL、用户名、密码、输出路径等命令行参数。内部私有化环境可以直接填写明文密码：

```python
ZABBIX_URL = "https://zabbix.example/zabbix"
ZABBIX_USER = "Admin"
ZABBIX_PASSWORD = "zabbix"
ZABBIX_TOKEN = ""  # 非空时优先使用 Token
OUTPUT_DIR = Path(__file__).resolve().parent / "exports"
TIMEOUT = 120
INSECURE = False
INCLUDE_SENSITIVE = True
TEMPLATE_IDS = []
TEMPLATE_NAMES = []
EXPORT_ALL = True
```

运行：

```sh
python3 export_zabbix54_templates.py
python3 export_zabbix54_templates.py --help
python3 export_zabbix54_templates.py --version
```

`TEMPLATE_IDS` 或 `TEMPLATE_NAMES` 用于缩小范围；`EXPORT_ALL=True` 且未指定筛选时导出全部可见模板。脚本会递归补齐父模板。

账号/Token 应具备 `template.get`、`configuration.export`、`trigger.get`、`triggerprototype.get` 和 `item.get` 权限。默认 `INSECURE=False` 校验证书；可信自签环境才改为 `True`。

## 输出文件

每次在 `OUTPUT_DIR` 下创建带时间戳的新目录：

- `templates.json`：Zabbix `configuration.export` 返回的完整模板结构，包含监控项、LLD、触发器、图形、宏和模板链接等。
- `alert-rules.json`：通过 API 单独获取的触发器、触发器原型、关联主机、函数、依赖、标签、监控项、预处理和值映射；`expression` 和 `recovery_expression` 可用于整理 EasyOps 告警模板及阈值。
- `template-index.json`：API/脚本版本、模板和父模板关系、各类告警数据数量。

`INCLUDE_SENSITIVE=True` 会原样保留 API 返回值，适合用户描述的内部私有化环境；如需对外分享请改为 `False` 并人工审查。

## 边界

只导出模板及其规则，不导出主机清单、主机级宏覆盖、全局宏、实时值、历史值或用户信息。父模板不可见、权限不足或 API 版本不是 5.4.x 时脚本会失败并记录 traceback。


## Python 2 版本

`export_zabbix54_templates_py2.py` 已同步模板、触发器、触发器原型和监控项阈值导出，配置方式同 Python 3 版本：直接修改脚本顶部变量后运行。当前为私有化直配模式，不再调用 `getpass`；因此不会再出现 Python 2 的 `str/unicode` 提示类型错误。

```sh
python2 export_zabbix54_templates_py2.py
```
